# Emlawtech

Emlawtech is an open-source, Stellar-based escrow platform for freelance and
service marketplaces. A client locks funds, a freelancer delivers, and the
funds are released on approval, with an arbiter available if the two sides
disagree.

> **Status:** early development. The escrow rules and a small HTTP API exist
> today. Real on-chain settlement on Stellar is not wired up yet; see the
> [roadmap](ROADMAP.md).

More documentation is coming in follow-up commits.
