Open source · Built for Stellar

Get paid for the work. Pay for the work you get.

Emlawtech holds a client's payment in escrow, releases it when the work is approved, and brings in an arbiter when the two sides disagree.

View on GitHub

How it works

  1. Create an escrow naming the client, freelancer and arbiter.
  2. Fund it. The client locks the agreed amount.
  3. Deliver the work. The freelancer submits it for review.
  4. Release on approval, or automatically when the review window ends.

Project status

The escrow rules and a small HTTP API are working and tested. Settlement on the Stellar network, wallet sign-in and a full web app are still on the roadmap, and contributions are welcome.

MIT licensed. Early development, not yet suitable for real funds.
