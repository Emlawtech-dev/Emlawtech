# Code of Conduct

We want Emlawtech to be a welcoming place to learn and build, whatever your
experience level.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept feedback on the work, not the person.
- Help newcomers. Everyone started somewhere.

## Unacceptable behavior

- Harassment, discrimination, insults or personal attacks.
- Publishing other people's private information.
- Spam or bad-faith contributions, including pull requests made only to
  collect rewards without solving the issue.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and
block people who break these rules. Report problems to the maintainers by
opening a private security advisory on the repository or by contacting the
maintainer listed on the GitHub profile that owns it.
