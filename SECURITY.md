# Security Policy

Emlawtech is in early development and is **not yet suitable for real funds**.
There is no authentication and no on-chain settlement yet.

## Reporting a vulnerability

Please report security problems privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository (Security tab, "Report a vulnerability"). Do not open a
public issue for security reports.

Include what you found, how to reproduce it, and the impact you expect. You
will get an acknowledgement as soon as a maintainer can review it.

## Scope

In scope: the code in this repository. Out of scope: third-party services and
the Stellar network itself.
